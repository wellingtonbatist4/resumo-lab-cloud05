# Resumo do Lab - Cloud Computing Fundamentals

## 📚 O que aprendi neste lab:

### 1. **Modelos de Serviço em Nuvem**
   - **IaaS (Infraestrutura como Serviço)**: Fornece recursos básicos de computação, armazenamento e rede sob demanda (ex: AWS EC2).
   - **PaaS (Plataforma como Serviço)**: Oferece ambientes prontos para desenvolvimento/apps (ex: Heroku).
   - **SaaS (Software como Serviço)**: Aplicativos completos via navegador (ex: Gmail).

### 2. **Tipos de Nuvem**
   - **Pública**: Recursos compartilhados por múltiplos usuários (ex: AWS, Azure).
   - **Privada**: Infraestrutura dedicada a uma única organização.
   - **Híbrida**: Combinação de nuvens pública e privada.
   - **Multicloud**: Uso de múltiplos provedores simultaneamente.

### 3. **Benefícios Chave**
   - ✅ Escalabilidade: Ajuste dinâmico de recursos conforme demanda.
   - ✅ Economia: Redução de custos com hardware e manutenção.
   - ✅ Elasticidade: Alocação rápida de recursos.
   - ✅ Alta disponibilidade: Serviços acessíveis 24/7.

### 4. **Casos de Uso Comuns**
   - Armazenamento em nuvem (ex: Google Drive)
   - Big Data e Analytics
   - Machine Learning

## 🔧 Tecnologias/Habilidades Desenvolvidas:
- Conceitos fundamentais de cloud computing
- Diferença entre IaaS, PaaS e SaaS
- Tomada de decisão para escolher o tipo de nuvem
